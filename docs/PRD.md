# 사이트 설계도(PRD) — 공간 스타일 진단 테스트 (가제)

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
집 꾸미기가 막막한 사람이 8개 질문에 답하면 내 인테리어 스타일을 알려 주고, 이메일을 남기면 그 스타일의 추천 아이템을 보내 주는 테스트 사이트.

## 2. 손님
- 누가: 집 꾸미기가 막막한 사람
- 어디서 알고 오나: 인스타그램, 블로그·검색

## 3. 손님이 궁금한 것 (테스트하기 전에)
1. 몇 분 걸려요? → 질문 8개, 약 2분
2. 결과로 뭘 받아요? → 내 인테리어 스타일 + (이메일을 남기면) 추천 아이템
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 아직 없음
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 첫 화면 버튼 이름: 테스트 시작하기
- 결과 화면 핵심 버튼: 추천 아이템 받기 (이메일 남기기)
- 함께 두는 버튼: 결과 공유하기
- 누르면: 이메일 입력 폼 → 저장 + 추천 아이템 메일 자동 발송

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + "질문 8개 · 약 2분" + 테스트 시작하기 버튼
2. 질문 화면 — 한 화면에 질문 하나, 진행 막대(1/8 … 8/8)
3. 결과 화면 — 내 스타일 이름·설명 → 결과 공유하기 → 추천 아이템 받기(이메일 폼)
4. 후기 자리 (비워 둠)
5. 관리자 페이지 /admin — 남긴 이메일과 결과 스타일 목록

결과 스타일 (3가지)
- 미니멀·모던
- 내추럴·우드
- 빈티지·미드센추리

테스트 질문 8개의 내용과 스타일별 추천 아이템 목록: (미정 — 사용자가 정하거나, 만들 때 초안을 보여 주고 확인받는다)

## 7. 이메일 폼에서 받을 것
- 이메일
- 결과 스타일 (자동으로 함께 저장)
- 개인정보 수집·이용 동의 (필수)
- 추천 아이템 메일 수신 동의 (필수) — 메일을 계속 보낸다면 광고성 정보 수신 동의도 따로 받는다

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 시간: 질문 8개, 약 2분
- 위치: 해당 없음 (온라인)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 아이템 구매·결제
- 내 방 사진 올리기 (기본으로 다음에)
- 블로그·스타일 상세 글 (기본으로 다음에)

## 10. 첫 화면 한 문장 후보
1. 우리 집, 어떤 스타일로 꾸며야 할지 막막하다면 — 2분 만에 내 공간 스타일 찾기
2. 8가지 질문으로 알아보는 나의 인테리어 스타일
3. 집 꾸미기, 내 취향부터 알고 시작해요

## 11. 다음에 할 것
- 회원가입·로그인
- 추천 아이템 구매·결제
- 내 방 사진 올리기
- 스타일별 상세 글·블로그
- 실제 후기가 생기면 후기 자리 채우기
- 결과 스타일 늘리기 (북유럽 등)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 이메일 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 추천 아이템 메일: 자동 발송 → 메일 발송 서비스 연결이 필요하다 (서비스의 API 키는 사용자가 직접 입력)
- 결과 공유: 결과별 공유 링크 + 링크 복사 버튼 (인스타그램 공유를 위해 결과 화면은 캡처하기 좋게)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. 질문 8개 → 결과 3가지 계산 → 결과 화면·공유 버튼을 만든다
3. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
4. 이메일 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
5. 메일 발송 서비스를 연결해 이메일을 남기면 추천 아이템 메일이 자동으로 가게 한다
6. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력, 메일 발송 서비스 가입과 API 키 입력
